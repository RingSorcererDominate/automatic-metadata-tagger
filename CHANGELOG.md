## 🎯 Overview

**Automatic Metadata Tagger** is a powerful cross-platform tool that reads, generates, and writes **metadata** for your digital files — automatically. It combines **rule-based logic**, **machine learning models**, and **external metadata sources** (like MusicBrainz, TMDB, EXIF databases) to enrich your files with accurate, structured tags.

Instead of manually editing thousands of files, you point the tagger at a folder and let it do the work — safely, reversibly, and intelligently.

### 🧩 What It Handles

| File Type | Metadata Added |
|-----------|----------------|
| 🖼️ **Photos** | EXIF, GPS, date, camera, tags |
| 🎵 **Music** | Artist, album, genre, cover art |
| 🎬 **Videos** | Title, year, cast, subtitles |
| 📄 **Documents** | Author, keywords, summary |
| 📚 **eBooks** | Title, author, ISBN, series |
| 🗂️ **Generic files** | Custom tags, categories |

```bash
tagger init
```

Creates `~/.tagger/config.yaml`.

### 🪜 Stage 6 — Set API Keys

```yaml
sources:
  musicbrainz:
    enabled: true
    api_key: "YOUR_KEY"
  tmdb:
    enabled: true
    api_key: "YOUR_KEY"
  openlibrary:
    enabled: true
```

### 🪜 Stage 7 — Dry Run

```bash
tagger scan ~/Photos --dry-run
```

### 🪜 Stage 8 — Apply Tags

```bash
tagger apply ~/Photos --recursive
```

## 🎯 Workflows

### 📸 Photo Tagging

```bash
tagger scan ~/Photos \
  --type image \
  --add gps,date,camera \
  --face-detect \
  --model clip
```

### 🎵 Music Library

```bash
tagger scan ~/Music \
  --type audio \
  --source musicbrainz \
  --fetch-cover-art \
  --rename-pattern "{artist}/{album}/{track} - {title}"
```

### 🎬 Video Collection

```bash
tagger scan ~/Videos \
  --type video \
  --source tmdb \
  --fetch-subtitles \
  --language en
```

### 📚 eBook Library

```bash
tagger scan ~/Books \
  --type ebook \
  --source openlibrary \
  --extract-isbn \
  --fetch-covers
```

### 🗂️ Bulk Generic Files

```bash
tagger scan ~/Documents \
  --recursive \
  --classify-documents \
  --extract-keywords \
  --output report.csv
```

## 🛠️ Custom Pipelines

### 📄 Pipeline Config Example

```yaml
pipeline:
  name: "Photo Library Enrichment"
  steps:
    - name: read_exif
      type: extractor
      fields: [date, gps, camera, lens]
    
    - name: face_detect
      type: ml
      model: insightface
      tags: [person]
    
    - name: classify_scene
      type: ml
      model: clip
      labels: [beach, mountain, city, food]
    
    - name: write_metadata
      type: writer
      format: xmp+exif
```

### 🔗 Chaining Steps

```bash
tagger run pipeline.yaml --input ~/Photos --verbose
```

## 🩺 Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| 🚫 Wrong tags | Bad match | Manual override |
| 🚫 Source rate limit | Too many requests | Add delay |
| 🚫 ML model fails | Missing deps | Install torch/onnx |
| 🚫 Metadata not written | Read-only files | Fix permissions |
| 🚫 Encoding errors | Legacy formats | Convert first |
| 🚫 Slow scan | Huge library | Use SSD cache |
| 🚫 Revert fails | No backup | Enable auto-backup |
| 🚫 API key invalid | Expired | Regenerate |
| 🚫 GPU not used | Driver | Install CUDA |
| 🚫 Crash on rare file | Corruption | Skip with `--skip-broken` |

### 🔄 Revert Last Run

```bash
tagger revert --run-id latest
```

## 💬 FAQ

**Is it free?**
Yes — MIT-licensed, open source.

**Does it modify original files?**
Safely — with automatic backups and revert support.

**Can I use it offline?**
Yes — for rule-based tagging; ML models run locally.

**Is my data uploaded anywhere?**
Only metadata queries to sources you enable.

**Does it work with RAW photos?**
Yes — via EXIF and XMP sidecars.

**Can I batch-tag thousands of files?**
Yes — the pipeline is designed for scale.

**Does it support custom metadata?**
Yes — arbitrary key-value pairs.

**Can I integrate it into scripts?**
Yes — full CLI and REST API.

**Does it rename files?**
Yes — with pattern templates.

**Is there a GUI?**
Yes — desktop and web interfaces.
